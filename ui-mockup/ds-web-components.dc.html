Component Web · theme admin

Bộ @fnb/ui-web (shadcn/ui · Radix · Tailwind 4), dùng chung cho Admin và web khách. Trang này là theme admin: đơn giản, gọn, điều khiển 40 px, radius-md, chỉ font-sans, không hoạ tiết. Theme customer ở trang bên cạnh. Component POS/KDS nằm ở bộ @fnb/ui-pos.
Button · DangerButton
