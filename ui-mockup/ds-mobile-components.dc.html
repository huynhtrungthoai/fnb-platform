Component Mobile · theme mobile

Bộ @fnb/ui-mobile: thiết kế chung cho Zalo Mini App (bản React DOM) và app native nếu sau này viết (D-43). App khách hiện là vỏ WebView bọc web khách, dùng @fnb/ui-web theme customer (D-42). Theme mobile theo cùng quy tắc thương hiệu với theme customer của web khách. Ưu tiên một cột, chạm bằng ngón cái: vùng chạm ≥ 44 px, nút chính 52 px. Mức thương hiệu cao: đầu trang brick + sóng, tiêu đề Baloo 2, ảnh món lớn. Giọng văn "quán" – "bạn".
